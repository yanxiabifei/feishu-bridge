# 截图与演示拍摄清单

README 的「它长什么样」要的是**真实手机截图**，不摆拍、不合成。这份清单说明拍什么、怎么拍、哪些东西不能进画面。

## 需要拍的三张

| 文件名 | 画面 | 怎么弄出来 |
|---|---|---|
| `01-group-reply.png` | 群聊里 @机器人 发一句话，下面是 Claude 的回复卡片 | 手机建一个测试群，拉机器人进群，发「@机器人 你好」 |
| `02-status.png` | 私聊里发「状态」后收到的健康面板（纯文本） | 点机器人头像进私聊，发「状态」 |
| `03-list.png` | 私聊里发「列表」后收到的总控面板（会话列表 + 别名按钮） | 私聊发「列表」 |

可选（有就更好）：

- `04-codex.png`：Codex 会话的「🖥 Codex 输出」卡片。本机 Codex 还没登录，拍不了可以跳过。
- `05-fullscreen.png`：点卡片上的「全屏」按钮后回的那张 200 行画面卡片。

## 怎么拍

1. 竖屏全屏截图就行，不用裁、不用调色，**原图 PNG** 给我。
2. 深浅色模式都行，但三张统一一种。
3. 卡片要完整入镜、字能看清；不要截图后再放大缩小。
4. 命名成上面的文件名，放到 `D:\tmp\shots\`，然后告诉我一声。

## 隐私自查（拍之前先看一眼）

- 不要出现真实 App ID / App Secret / 任何 token（一般只在电脑终端里，别拍到终端）。
- 群名用测试群，比如「飞书自测」；别名用「草稿」这类通用词。
- 手机号、真实姓名、其他群/聊天记录、头像，能避就避开；实在避不开，用系统相册的涂鸦打码。
- 卡片里的路径可以出现 `D:/...`，但不能出现用户名目录（`C:/Users/<你的名字>/...`）。

## 演示录屏（可选，30 秒）

手机自带录屏，一遍过：

1. 从建群开始（或直接进测试群）；
2. @机器人 发一句「列出这个目录的文件」；
3. 等回复卡片出现，停两秒结束。

MP4 原文件放同一个目录。录屏里**不要**切到私聊、不要露出其他群。
